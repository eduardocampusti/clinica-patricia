08/10/2026 do repositório oficial https://github.com/notofonts/noto-fonts,
diretório `hinted/ttf/NotoSans`. Licença SIL Open Font License 1.1 em `OFL.txt`.
Permite redistribuição e incorporação; a licença da fonte não se estende aos PDFs.

SHA256 Regular: b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5.
SHA256 Bold: c976e4b1b99edc88775377fcc21692ca4bfa46b6d6ca6522bfda505b28ff9d6a.

Carregadas do próprio pacote, uma vez por sessão, somente quando necessárias.
Não instalar no Windows nem substituir por fonte do sistema silenciosamente.
