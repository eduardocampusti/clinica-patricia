## Claude Design — Dashboard principal (já usado)

```
Crie o dashboard principal de um sistema médico multiespecialidade, em português.
Usuária logada: proprietária da clínica, vendo o painel do dia.

Estrutura da tela:
- Sidebar fixa à esquerda com navegação: dashboard, agenda, pacientes,
  prontuário, financeiro, relatórios, configurações
- Cabeçalho com saudação personalizada ("Olá, [nome]")
- Card de destaque: "Fluxo de caixa do dia" — saldo em números grandes,
  com indicador visual de entradas vs. saídas
- Card: "Atendimentos de hoje" — lista com paciente, especialidade,
  horário e status (badge de cor suave)
- Card: "Resumo por especialidade" — indicadores de quantos atendimentos
  cada especialidade teve no dia

Tom: calmo, profissional, confiável, fácil de escanear em poucos segundos.
```

## Claude Design — Ajuste de sidebar (roxo escuro, já usado)

```
Mude o fundo da barra lateral (menu) para roxo escuro/indigo profundo,
parecido com #2E1A47, com os textos e ícones do menu em branco.
O item de menu ativo (selecionado) deve ter um destaque visível,
como um fundo levemente mais claro ou uma barra colorida na lateral.
```

## Claude Design — Seletor de clínica com rótulo (Opção A, já usado)

```
No seletor de clínicas, adicione um pequeno rótulo acima ou ao lado dele com o
texto "Visão proprietária", em fonte menor e cor suave, para deixar claro que
apenas a proprietária tem acesso a todas as clínicas. O rótulo deve ser discreto,
não competir visualmente com o nome da clínica. Mantenha todo o resto igual.
```
